# 🛍️ Список покупок

Одностраничное приложение для учёта желаемых покупок: категории, цены в разных валютах, ссылки и автоматические итоги. Полностью заменяет таблицу.

**Весь код — в одном файле `index.html`.** Без сборки, без зависимостей, без бэкенда.

## Возможности

- ➕ Форма добавления: название, цена + валюта (₴ UAH по умолчанию или $ USD), категория, ссылка
- 🔗 Ссылка превращается в компактную кнопку **«Открыть ↗»** (в новой вкладке); `eva.ua/pr123` автоматически превращается в `https://…`
- 🗂️ Свои категории: создание, переименование, удаление (товары при удалении можно перенести в «Без категории»)
- 🧮 Итоги сверху: «Осталось купить» / «Уже куплено» + разбивка по каждой категории
- ✅ Отметка «куплено» — зачёркивание, суммы разделяются на остаток и купленное
- 💱 Смешанные валюты считаются отдельно по каждой (без конвертации)
- 🌗 Светлая и тёмная тема (запоминается)
- 📱 Адаптивная вёрстка под телефон
- 💾 Данные в `localStorage` браузера + экспорт/импорт JSON-бэкапа

## Запуск локально

Просто откройте `index.html` в браузере. Всё.

## Деплой на Render (static site)

1. Залейте файлы в репозиторий GitHub:
   ```bash
   git init
   git add .
   git commit -m "shopping list app"
   git branch -M main
   git remote add origin https://github.com/<ВАШ_НИК>/<РЕПО>.git
   git push -u origin main
   ```
2. На [render.com](https://dashboard.render.com) → **New +** → **Static Site**
3. Подключите репозиторий, настройки подставятся из `render.yaml` (или вручную):
   - **Build Command:** *пусто*
   - **Publish Directory:** `.`
4. **Deploy Static Site** — готово, сайт будет на `https://<имя>.onrender.com`

## Альтернатива: GitHub Pages

Settings → Pages → Source: `main` / `(root)` → Save. Сайт появится на `https://<ник>.github.io/<репо>/`.

## Важно знать

- Данные хранятся локально в браузере устройства: на другом устройстве/в другом браузере список пустой. Для переноса используйте **Экспорт → Импорт** (кнопки внизу страницы).
- Причистку кэша/данных сайта в браузере список тоже сотрётся — периодически делайте экспорт.
